DISCIPLINE HQ — FUTURISTIC REDESIGN + JARVIS

Files:
- index.html
- styles.css
- app.js
- jarvis.js
- design-reference.png (visual reference only)

Install:
1. Back up your current GitHub files.
2. Replace index.html, styles.css, and app.js with these versions.
3. Add jarvis.js beside index.html.
4. Commit changes and reload your website.

Notes:
- Existing app.js behavior is preserved and includes small search/theme enhancements.
- Jarvis currently uses predefined local replies. Gemini is not connected yet.
- Chat history is local to this browser and does not sync across devices.
- The design background is recreated with CSS space/earth-inspired lighting, orbital arcs, and a sunrise glow. The reference screenshot itself is not stretched as the site background because that would duplicate its text and UI.
- Please test the site after deploying; I have not run this in your live browser.
- Never put a Gemini API key in browser-visible JavaScript; later integration should use a secure backend endpoint.
