DISCIPLINE HQ — EARTH-ORBIT VISUAL UPDATE (NO JARVIS)

This package includes:
- index.html
- styles.css
- app.js
- assets/earth-orbit-background.png

Install:
1. Back up your current repository files.
2. Replace index.html, styles.css, and app.js with the versions here.
3. Upload the entire `assets` folder (including earth-orbit-background.png) into the same root directory as index.html.
4. Commit the changes to main.
5. Wait for GitHub Pages to deploy, then hard refresh with Ctrl+Shift+R.

Important:
- The background artwork is a separate generated image asset, not a screenshot with UI baked into it.
- The dashboard, navigation, checklist, history, analytics, reflections and settings remain actual HTML/JS components.
- Jarvis has been removed.
- This is a screenshot-inspired functional recreation, not a guarantee of pixel-for-pixel identity across every display size; the reference image is a flattened picture and does not contain the original component code.
- Test all views after deployment. The live browser was not available for direct validation.
